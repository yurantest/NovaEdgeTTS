# Nova Edge TTS

Системный TTS-движок для Android с голосами Microsoft Edge (322 голоса, 70+ языков).

После установки появляется в настройках Android → Синтез речи. Любое приложение (читалка, браузер, навигатор) может выбрать его и озвучивать текст голосами Светланы, Дмитрия и других.
